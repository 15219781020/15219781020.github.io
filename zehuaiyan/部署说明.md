# 泽怀晏 · 个人主页 部署说明

## 文件
- `index.html` —— 主页（已生成，可直接使用）

## 方式一：GitHub Pages（免费，推荐）

1. 注册 GitHub：https://github.com ，验证邮箱
2. 右上角 `+` → New repository
3. 仓库名填：`你的用户名.github.io` （必须是你的用户名）
   - 例：用户名为 zehuaiyan → 仓库名 `zehuaiyan.github.io`
4. 选 Public → 勾 Add a README → Create repository
5. 进仓库 → 点 Add file → Upload files → 上传 `index.html`
6. Settings → Pages → Source 选 `main` 分支 → Save
7. 等待 1-2 分钟，打开 `https://你的用户名.github.io`

## 方式二：Vercel（更快，国内访问友好）

1. 注册 https://vercel.com （可用 GitHub 账号登录）
2. 点 Import Project → 导入刚才的 GitHub 仓库
3. Framework Preset 选 **Other** → Deploy
4. 几十秒后获得域名，如 `https://zehuaiyan.vercel.app`

## 本地预览

双击 `index.html` 即可用浏览器打开预览。

## 需要修改的地方

1. 联系方式：把 `mailto:your@email.com` 改成你的邮箱
2. GitHub 链接：把 `yourname` 改成你的 GitHub 用户名
3. 作品区：把三个示例卡片换成你自己的作品（书法照片、比赛视频、棋谱等）
4. 简介文字：直接改 `<p>` 里的内容

## 绑定自己的域名（可选）

1. 在阿里云 / 腾讯云 / Namecheap 买域名（.com 约 50-100 元/年）
2. 在 Vercel / GitHub Pages 设置里添加 Custom Domain
3. 到域名服务商处添加 CNAME 解析
4. 自动开启 HTTPS

## 提示

- 图片请先压缩（可用 Caesium / Squoosh），避免主页加载慢
- 建议把书法、球赛照片放到 `images/` 文件夹，用 `<img src="images/xxx.jpg">` 引用
- 修改后重新上传即可更新网站
